# Einstellung / functional fixedness

*Designer tendencies*

Signal: Reaching for the familiar pattern even when the problem differs. Counter: Re-describe the problem without UI nouns; ask "what would this be if not a screen?".

- **Evidence:** Luchins 1942; Duncker 1945 · Strong
